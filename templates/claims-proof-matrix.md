# Claims Proof Matrix

## Status definitions

- Open: no implementation or proof.
- Implemented: code exists and is wired.
- Proved: deterministic tests support the claim.
- Live validated: the real or realistic external path was exercised, and the result supports the claim.
- Stale: the source or architecture changed after evidence was recorded.

## Claim record

- Status: [status]
- Scope: [exact boundary]
- Source revision: [commit or digest]
- Implementation: [path]
- Automated proof: [test and result]
- Live or realistic proof: [artifact and result]
- Limitations: [what this does not prove]
- Revalidation trigger: [change that makes evidence stale]
- Owner: [human]

Duplicate this record for each important product, security, architecture, sales, or release claim.
